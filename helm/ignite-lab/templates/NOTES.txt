{{ include "ignite-lab.fullname" . }} is installing {{ .Values.replicaCount }} Ignite {{ .Chart.AppVersion }} node(s).

Watch them start:
  kubectl --namespace {{ .Release.Namespace }} rollout status statefulset/{{ include "ignite-lab.fullname" . }}

{{ if .Values.clusterInit.enabled -}}
The cluster is initialized by a post-install job named
{{ include "ignite-lab.fullname" . }}-cluster-init. Check it with:
  kubectl --namespace {{ .Release.Namespace }} logs job/{{ include "ignite-lab.fullname" . }}-cluster-init
{{- else -}}
clusterInit is disabled, so the nodes stay in STARTING. Initialize manually:
  kubectl --namespace {{ .Release.Namespace }} exec -it {{ include "ignite-lab.fullname" . }}-0 -- \
    /opt/ignite3cli/bin/ignite3 cluster init \
      --url http://localhost:{{ .Values.ports.rest }} \
      --name={{ .Values.clusterInit.clusterName }} \
      --metastorage-group={{ include "ignite-lab.nodeNames" . }}
{{- if .Values.auth.enabled }}

Security is cluster configuration, so it is applied after init. Set the
password before enabling it, or the account is locked out:
  kubectl --namespace {{ .Release.Namespace }} exec -it {{ include "ignite-lab.fullname" . }}-0 -- \
    /opt/ignite3cli/bin/ignite3 cluster config update \
      --url http://localhost:{{ .Values.ports.rest }} \
      'ignite.security.authentication.providers.default.users.{{ .Values.auth.user }}.password="<password>"'
  kubectl --namespace {{ .Release.Namespace }} exec -it {{ include "ignite-lab.fullname" . }}-0 -- \
    /opt/ignite3cli/bin/ignite3 cluster config update \
      --url http://localhost:{{ .Values.ports.rest }} \
      'ignite.security.enabled=true'
{{- end }}
{{- end }}
{{ if .Values.auth.enabled }}
Authentication is enabled for user {{ .Values.auth.user | quote }}. Read the password with:
  kubectl --namespace {{ .Release.Namespace }} get secret {{ include "ignite-lab.secretName" . }} \
    -o jsonpath='{.data.password}' | base64 -d
{{- end }}

Reach the cluster from your machine:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ignite-lab.fullname" . }} {{ .Values.ports.rest }}:{{ .Values.ports.rest }} {{ .Values.ports.client }}:{{ .Values.ports.client }}
  curl {{ if .Values.auth.enabled }}-u {{ .Values.auth.user }}:<password> {{ end }}http://127.0.0.1:{{ .Values.ports.rest }}/management/v1/cluster/state

{{ if and .Values.auth.enabled (not .Values.auth.existingSecret) -}}
WARNING: using the default lab password from values.yaml. Set auth.password or
auth.existingSecret before this is reachable by anyone else.
{{- end }}
{{ if not .Values.auth.enabled -}}
WARNING: auth.enabled is false. The REST and client ports accept anonymous
access from anything that can reach them.
{{- end }}
